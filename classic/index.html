Orderbook Engine

Project snapshot ↗
● ● ● orderbook-engine / README

nishant@portfolio:~$ about orderbook-engine

  • I built a limit order book from scratch in C++, using CMake to build the engine.
  • It matches incoming buy and sell orders by price, then arrival time, handling partial fills, cancellations, and trades across multiple price levels.
  • The project helped me understand how an exchange turns available liquidity into executed trades.

CNN Chess Engine

Project snapshot ↗
● ● ● cnn-chess-engine / README

nishant@portfolio:~$ about cnn-chess-engine

  • I used Python and TensorFlow to explore whether a convolutional neural network could learn useful chess decisions.
  • I tried predicting moves from Grandmaster games and approximating Stockfish’s position evaluations.
  • Neither approach produced a competitive engine. The archived experiment taught me about board representations, training data, and the limits of supervised learning for chess.

DATA · EDUCATION

KCET Answer Key

Project snapshot ↗
● ● ● kcetanswerkey / README

nishant@portfolio:~$ about kcetanswerkey

  • I used Python, image preprocessing, and data analysis to extract answers from 900,000+ publicly released KCET OMR scans.
  • The pipeline estimated marks for nearly 300,000 students, handling noisy scanned sheets with a reported error rate of around 2–3%.
  • I used that dataset to build a rank predictor, helping students estimate where their scores might place them. The website reached 20,000+ visitors.
