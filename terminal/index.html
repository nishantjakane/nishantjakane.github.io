Orderbook Engine

nishant:~$ ./build/Release/OrderBook.exe

  • Built a C++ matching engine with CMake. Maintains 2 separate books—bids and asks—and matches orders by price, then arrival time.
  • Handles partial fills, cancellations, and trades across multiple price levels to explore exchange mechanics.
  • The README estimates ~1–5M orders/sec; this is an estimate, not a formally measured benchmark.
